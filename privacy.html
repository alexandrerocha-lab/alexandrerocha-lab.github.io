Política de Privacidade

Última atualização: 12 de outubro de 2026

Esta política explica como o Mr Rocha Uploader ("a ferramenta") acessa, usa, armazena e compartilha dados. A ferramenta é de uso pessoal e é usada somente pelo seu desenvolvedor, Alexandre Rocha, nos próprios canais do YouTube.

Serviços de API do YouTube

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelos serviços do Google estão sujeitos à Política de Privacidade do Google.

Quais dados são acessados

Depois que o dono do canal autoriza o acesso pelo login OAuth 2.0 do Google, a ferramenta acessa:

  • a identificação do canal autorizado (ID e nome), para confirmar que o vídeo vai para o canal certo;
  • os vídeos, títulos, descrições, tags, datas de agendamento e comentários que o próprio criador prepara e envia;
  • o status de privacidade dos vídeos enviados, para saber quando o comentário de abertura pode ser publicado;
  • as playlists do canal, quando o vídeo é adicionado a uma série.

A ferramenta não acessa dados de espectadores, inscritos, mensagens, histórico ou informações de pagamento.

Como os dados são usados

Os dados são usados apenas para enviar, agendar e organizar os vídeos do próprio criador e publicar o comentário de abertura dele. Não há publicidade, criação de perfis, análise de terceiros nem venda de dados.

Armazenamento

A ferramenta roda somente no computador do criador. Os tokens de acesso do Google e um registro dos envios (ID do vídeo, título e data) ficam salvos localmente nesse computador. Não existe servidor nem banco de dados externo. A ferramenta não usa cookies.

Compartilhamento

Nenhum dado é compartilhado com terceiros. As informações são enviadas somente ao próprio YouTube/Google, para fazer o envio solicitado pelo dono do canal.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google: security.google.com/settings/security/permissions. Para apagar os dados armazenados, basta excluir a pasta de credenciais da ferramenta no computador. Pedidos de exclusão enviados pelo contato abaixo são atendidos em até 7 dias. Dados obtidos da API que deixam de ser necessários são apagados ou atualizados em até 30 dias.

Contato

Dúvidas sobre esta política: alexandrerocha.sgs@gmail.com.

Privacy Policy

Last updated: October 12, 2026

This policy explains how Mr Rocha Uploader ("the tool") accesses, uses, stores and shares data. The tool is for personal use and is used only by its developer, Alexandre Rocha, on his own YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Data handled by Google services is subject to the Google Privacy Policy.

Data accessed

After the channel owner authorizes access through Google's OAuth 2.0 sign-in, the tool accesses:

  • the authorized channel's identity (ID and name), to confirm each upload goes to the correct channel;
  • the videos, titles, descriptions, tags, schedule times and comments that the creator prepares and uploads;
  • the privacy status of uploaded videos, to know when the opening comment can be posted;
  • the channel's playlists, when a video is added to a series.

The tool does not access viewer data, subscriber data, messages, watch history or payment information.

How data is used

Data is used only to upload, schedule and organize the creator's own videos and to post his opening comment. There is no advertising, profiling, third-party analytics or sale of data.

Storage

The tool runs only on the creator's computer. Google access tokens and an upload log (video ID, title and date) are stored locally on that computer. There is no server or external database. The tool does not use cookies.

Sharing

No data is shared with third parties. Information is sent only to YouTube/Google to perform the upload requested by the channel owner.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page: security.google.com/settings/security/permissions. To delete stored data, delete the tool's credentials folder on the computer. Deletion requests sent to the contact below are handled within 7 days. API data that is no longer needed is deleted or refreshed within 30 days.

Contact

Questions about this policy: alexandrerocha.sgs@gmail.com.
